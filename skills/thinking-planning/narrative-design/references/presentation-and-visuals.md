# Presentation And Visual Narrative

Use this for PowerPoint, slide outlines, visual explanations, executive decks,
briefings, speaker notes, and talk tracks.

## Sources And Influences

- Nancy Duarte / Resonate-style contrast: move between current state and
  possible future to create tension.
- Storytelling with Data: remove clutter and focus attention.
- Consulting-style storyline: answer first, then support with logically grouped
  evidence.

## Presentation Workflow

1. Define the meeting outcome before the title slide.
2. Write the one-sentence main message.
3. Choose a deck type:
   - **Decision deck**: recommendation and choice.
   - **Teaching deck**: build literacy and shared language.
   - **Strategy deck**: problem, diagnosis, direction, trade-offs.
   - **Progress deck**: status, variance, risks, decisions.
   - **Pitch deck**: belief change and commitment.
4. Storyboard with slide headlines only. If the headlines do not read as a
   coherent argument, the deck is not ready for design.
5. Add one job per slide: orient, prove, compare, choose, warn, explain, or ask.
6. Add speaker notes only where the slide needs narration beyond visible text.

## Slide Headline Rules

- Prefer assertion headlines: "Fabric is the production line behind reporting",
  not "Fabric overview".
- Make each headline advance the argument.
- Use short body text. Put nuance in speaker notes, appendix, or pre-read.
- Put the ask before the end if leaders need time to process it.

## Visual Rules

- Use diagrams for relationships, timelines for sequence, matrices for choices,
  and charts for quantified comparisons.
- Keep visual hierarchy clear: title, focal point, support.
- Do not use a chart where a sentence is clearer.
- Avoid decorative layouts that hide the decision.
- Use appendix for definitions, detailed architecture, and source depth.

## Deck Diagnostics

- Can the audience repeat the main message after slide 3?
- Does the deck say what decision is needed?
- Does each slide have a reason to exist?
- Are literacy slides separated from decision slides?
- Is there an obvious appendix boundary?
- Does the ending assign next action, owner, and timeline?
