# Data Storytelling

Use this for metrics, analysis, dashboards, BI, charts, KPIs, forecasts,
financial data, survey results, or performance reporting.

## Sources And Influences

- Cole Nussbaumer Knaflic, *Storytelling with Data*: understand context,
  choose an appropriate display, remove clutter, focus attention, think like a
  designer, tell a story.
- Common executive communication pattern: `what -> so what -> now what`.
- Minto-style logic: answer first, then support with grouped evidence.

## Data Story Workflow

1. **Context**: Who needs this data story, what decision do they face, and what
   do they already believe?
2. **Question**: What business, policy, operational, or strategic question is
   the data answering?
3. **Finding**: Write the finding in a sentence before choosing a chart.
4. **Evidence**: Pick the smallest number of views needed to support the
   finding.
5. **Implication**: Explain why it matters for money, risk, quality, capacity,
   service, strategy, compliance, or timing.
6. **Action**: Say what should happen next.

## Chart And Visual Rules

- Use the chart type that matches the comparison: time, ranking, composition,
  distribution, relationship, flow, or variance.
- Prefer direct labels and action titles over legends and generic titles.
- Remove decorative clutter unless it helps comprehension.
- Highlight only the point the audience must see.
- Show uncertainty, assumptions, and scope limits when they affect decisions.
- Avoid precision theater: do not imply confidence the data does not support.

## Useful Spines

### Performance Story

`target -> actual -> variance -> driver -> consequence -> action`

### Forecast Story

`baseline -> changed assumption -> scenario -> risk -> decision`

### Dashboard Story

`role -> question -> metric group -> drill path -> action`

### Data Quality Story

`intended use -> data gap -> risk -> remediation -> owner`

## Checks

- Can the main finding be understood without reading every axis?
- Does the story say why the result matters?
- Is the audience being asked to decide, investigate, approve, or change behavior?
- Are definitions and denominators clear?
- Would a skeptical domain expert accept the evidence?
