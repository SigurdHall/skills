# Knowledge Management Skills

Skills in this folder support Markdown notes, vault management, strategy
analysis, governance notes, source-based synthesis, and reusable knowledge
artifacts.

Current skills:

- `accomplishment-log`
- `strategic-plan-analysis`
- `vault-forvalter`
- `weekly-production-review`

## Ownership boundary (avoid two truths)

- `vault-forvalter` → general vault maintenance (classification, linking,
  decay, topic pages). Not accomplishment tracking.
- `accomplishment-log` → manual capture + full-period summarize of what the
  user has produced, for medarbeidersamtale/CV/jobbskifte.
- `git-push-daily-log` (under `coding/`) → automatic per-push log into
  today's Journal daily note. Technical detail level, not curated.
- `weekly-production-review` → weekly meta-summary of the two above. Not a
  full-career summary (that's `accomplishment-log` Mode 2).
- `strategic-plan-analysis` → governance/strategy document critique.
