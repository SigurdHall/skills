# Presentation Skills

Use these skills for decks, briefings, slide generation, visual storytelling,
meeting decks, and branded presentation outputs.

## Routing

- Use [uit-deck-generator](uit-deck-generator/SKILL.md) when the user asks for
  UiT-branded PowerPoint decks, UiT template compliance, deck generation from
  markdown/JSON/outlines, or validation of generated `.pptx` files.
- Use [presentation-factory](presentation-factory/SKILL.md) when the user asks
  for premium HTML-first presentations, image-led decks, branded or non-work
  decks, controlled image generation, hybrid PPTX export, or a reusable staged
  presentation workflow.
- Use [thinking-planning/narrative-design](../thinking-planning/narrative-design/SKILL.md)
  first when the issue is storyline, persuasion, red thread, meeting purpose,
  or slide sequencing rather than actual `.pptx` generation.
- Use [thinking-planning/grill-me](../thinking-planning/grill-me/SKILL.md)
  when the deck needs hard pressure-testing before a leadership meeting.

## Defaults

- Keep leader decks decision-oriented and sparse.
- Split literacy, appendix, and mandate content into separate decks when one
  deck starts serving multiple audiences.
- Preserve official templates, layouts, colors, and background graphics when
  generating `.pptx` files.
